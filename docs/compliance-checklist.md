# 合规与审核清单

## 开源披露

- Tesseract.js：Apache-2.0，H5 备用 OCR。
- pdf-lib：MIT，H5 与云函数 PDF 生成/合并。
- React/Vite：MIT，H5 前端。
- 腾讯云 OCR SDK：云函数依赖，按腾讯云服务协议使用。

## 用户文件处理

| 文件类型 | 处理方式 | 存储策略 |
|---|---|---|
| OCR 图片 | 上传云函数识别 | 仅用于识别，需配置短期删除 |
| 扫描图片 | 上传云函数生成 PDF | 仅用于生成 PDF，需配置短期删除 |
| PDF 文件 | 上传云函数合并 | 仅用于合并，需配置短期删除 |
| 图片工具文件 | 小程序本机处理 | 不上传 |

## 必须展示的用户说明

- OCR/PDF 会短期上传云端处理。
- 票据、合同、证件、简历可能包含敏感信息。
- 最近记录仅保存工具名、文件名/任务名和状态，不保存文件内容。
- 未配置 OCR 服务时不能识别文字。

## 微信隐私能力

- `chooseMedia`：选择图片/拍照。
- `chooseMessageFile`：选择聊天 PDF。
- `saveImageToPhotosAlbum`：保存图片结果。
- `setClipboardData`：复制 OCR 文本。
- 云开发文件上传：OCR/PDF 处理。

## 上线阻断

- 云函数返回错误但页面显示成功。
- OCR 未配置凭证却展示模拟文本。
- PDF 没有真实 `fileID` 却进入结果页。
- 用户文件上传说明缺失。
- 保存相册失败无权限引导。

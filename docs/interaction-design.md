# 小程序交互设计说明

## 全局原则

- 每个工具都保持 `选择文件 → 处理 → 结果` 三步。
- 任何未完成能力不得用成功页包装。
- 处理任务超过 3 秒必须显示 loading 和明确文案。
- 错误提示必须包含下一步建议。

## 首页

- 默认态：顶部说明“小程序优先、云处理/本机可用”，下方四个工具入口。
- 最近记录：显示最近 5 次工具名和任务名，不显示文件内容。
- 反馈入口：说明反馈在结果页提交，避免首页堆表单。

## 拍图识字

- 默认态：说明 OCR 会短期上传云端处理。
- 选择态：显示图片预览、文件大小、开始识别按钮。
- 处理中：按钮 loading，文案为“开始识别”。
- 成功态：进入结果页，展示文本、置信度、耗时、复制按钮。
- 失败态：未配置云 OCR 时显示“服务未配置”；识别失败时建议换清晰图片。

## 扫描成 PDF

- 默认态：说明多图按当前顺序生成 PDF。
- 选择态：显示页序、体积、删除、上移。
- 处理中：逐个上传后调用云函数。
- 成功态：进入 PDF 结果页，显示页数、大小、预览、分享。
- 失败态：上传失败提示检查网络；PDF 生成失败提示换 JPG/PNG。

## PDF 工具

- 默认态：两个入口：选择 PDF 合并、选择图片转 PDF。
- 选择态：展示文件名和大小。
- 约束：PDF 合并至少 2 个文件；首版不展示拆分/提取页。
- 成功态：进入 PDF 结果页。

## 图片工具

- 默认态：说明本机处理。
- 控件：质量滑杆、最长边滑杆。
- 成功态：进入图片结果页，显示结果大小、节省比例、保存按钮。
- 权限态：保存失败时引导打开相册权限。

## 结果页

- 文本结果：textarea 展示识别文本，主按钮复制文字。
- PDF 结果：展示页数/大小，主按钮预览 PDF，次按钮分享 PDF。
- 图片结果：展示图片预览和节省比例，主按钮保存相册。
- 反馈：评分按钮 + 文本框 + 提交按钮，提交到 `feedbackSubmit`。
- 相邻工具：点击后回到对应小程序页面，不跳 H5。

# 项目发布管理

## 里程碑

| 阶段 | 目标 | 完成标准 |
|---|---|---|
| M1 小程序主体验 | 四入口端内流程成型 | OCR/PDF/图片工具不再以 H5 为主动作 |
| M2 云函数闭环 | OCR、PDF、反馈接口可部署 | 缺配置明确失败，mock 单测通过 |
| M3 上架资料 | PRD、交互、隐私、截图、审核路径齐全 | 文档可直接交给运营/审核 |
| M4 真机验收 | iPhone/Android/微信开发者工具通过 | 验收矩阵无阻断项 |
| M5 14 天复盘 | 看入口、输入、成功、导出、反馈 | 决定是否扩展二维码/证件照 |

## 风险登记

| 风险 | 等级 | 应对 |
|---|---|---|
| OCR 凭证未配置 | 高 | 页面显示服务未配置，不展示模拟结果 |
| 云函数 PDF 处理失败 | 高 | 返回错误码，结果页不显示成功 |
| 小程序文件上传慢 | 中 | 限制 10MB，显示 loading，失败可重试 |
| PDF 预览/分享兼容性 | 中 | 优先 `wx.openDocument`，分享失败提示从菜单分享 |
| H5 bundle 偏大 | 中 | OCR/PDF 动态加载，H5 降级为备用 |

## 决策规则

- OCR 导出率低：先看识别准确率和耗时，再考虑更换 OCR provider。
- PDF 成功率低：先限制文件类型和大小，再优化云函数。
- 首页点击率低：改工具命名和场景文案，不先扩功能。
- 反馈集中在某一工具：该工具优先修复，暂停新增工具。

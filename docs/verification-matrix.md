# 上线前验收矩阵

## 自动化

| 编号 | 命令 | 预期 |
|---|---|---|
| A-01 | `npm run typecheck` | TypeScript 通过 |
| A-02 | `npm test` | 单元测试、云函数契约、小程序静态检查通过 |
| A-03 | `npm run build` | H5 构建通过，主包不含静态 pdf-lib 主依赖 |
| A-04 | `npm audit --audit-level=critical` | 0 critical vulnerabilities |

## 小程序

| 编号 | 路径 | 步骤 | 预期 |
|---|---|---|---|
| MP-01 | 首页 | 打开 home | 显示四入口、云处理/本机可用、最近记录、反馈说明 |
| MP-02 | OCR | 选图 → 开始识别 | 未配置 OCR 时显示服务未配置；配置后进入文本结果页 |
| MP-03 | 扫描成 PDF | 选 2 张图 → 上移/删除 → 生成 PDF | 返回真实 fileID，结果页可预览 PDF |
| MP-04 | PDF 工具 | 选 2 个 PDF → 合并 | 返回真实 fileID，结果页可预览/分享 |
| MP-05 | 图片工具 | 选图 → 调质量/最长边 → 处理 | 结果页显示大小和节省比例，可保存相册 |
| MP-06 | 结果页 | 提交反馈 | 调用 feedbackSubmit，成功/失败都有提示 |
| MP-07 | 相邻工具 | 点击推荐工具 | 跳到小程序工具页，不跳 H5 |

## 真机

| 环境 | 必测 |
|---|---|
| iPhone + 微信 | OCR、PDF 预览、分享 PDF、保存相册 |
| 低端 Android + 微信 | 上传失败重试、10MB 限制、loading 不假死 |
| 微信开发者工具 | 云函数上传、云环境配置、数据库反馈写入 |

## 上线阻断

- 任一核心工具出现假完成。
- OCR/PDF 主按钮仍是 H5。
- 云函数错误没有中文提示。
- 结果不可导出或保存。
- 隐私、文件上传、开源披露缺失。

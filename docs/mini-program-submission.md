# 小程序上架基础资料

## 名称备选

1. 手机办公文件处理助手
2. 拍图识字 PDF 助手
3. 微信文件处理助手

推荐：`手机办公文件处理助手`。名称覆盖办公场景，不把产品锁死在 OCR 或 PDF 单点。

## 类目建议

- 工具 > 办公。
- 工具 > 图片处理。
- 教育相关内容仅作为场景描述，不作为主类目。

## 简介

在微信里快速完成拍图识字、扫描成 PDF、PDF 合并、图片压缩和改尺寸。无需安装 App，常用文件处理三步完成。

## 关键词

拍图识字、图片转文字、OCR、扫描成 PDF、图片转 PDF、PDF 合并、图片压缩、压图、文件处理、办公助手。

## 隐私权限说明

| 能力 | 用途 | 用户提示 |
|---|---|---|
| `chooseMedia` | 拍照或选择图片 | 用于 OCR、扫描 PDF、图片处理 |
| `chooseMessageFile` | 从聊天选择 PDF | 用于 PDF 合并 |
| `saveImageToPhotosAlbum` | 保存图片结果 | 仅在用户点击保存时触发 |
| `setClipboardData` | 复制 OCR 文本 | 仅复制用户主动处理后的文字 |
| 云开发文件上传 | OCR/PDF 短期处理 | 上传用于处理，不公开展示 |

## 审核测试路径

1. 首页打开 `/pages/home/home`。
2. 进入“图片工具”，选择图片，处理后保存相册。
3. 进入“拍图识字”，选择图片。若未配置 OCR 凭证，应看到“服务未配置”错误。
4. 配置云函数后，进入“扫描成 PDF”，选择 2 张 JPG/PNG，生成 PDF，预览。
5. 进入“PDF 工具”，从聊天选择 2 个 PDF，生成合并结果。
6. 在结果页提交反馈。

## 截图清单

- 首页四入口。
- 拍图识字选择态和结果态。
- 扫描成 PDF 多图列表。
- PDF 工具选择文件态。
- 图片工具处理结果态。
- 统一结果页反馈区。

## 上线阻断

- OCR/PDF 页面仍以 H5 为主按钮。
- 云 OCR 未配置却展示模拟结果。
- PDF 没有真实文件结果就进入成功页。
- 缺少隐私说明、文件处理说明或开源披露。
- 保存相册失败无权限引导。

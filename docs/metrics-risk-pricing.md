# 指标、风险与商业化策略

## 指标框架

North Star Metric：每周小程序端完成并导出的办公文件处理任务数。

| 指标 | 说明 |
|---|---|
| 工具入口点击率 | 点击任一工具 / 首页访问 |
| 输入完成率 | 文件通过校验 / 工具页访问 |
| 处理成功率 | 成功结果 / 开始处理 |
| 导出率 | 复制、预览、分享、保存 / 成功结果 |
| 反馈率 | 提交反馈 / 成功结果 |
| 二次访问率 | 7 天内再次访问 / 导出用户 |

## 风险假设

| 风险 | 等级 | 验证 |
|---|---|---|
| 云 OCR 未配置或准确率不足 | 高 | 错误码、反馈、导出率 |
| PDF 云函数处理失败 | 高 | 云函数日志、失败率 |
| 小程序上传慢 | 中 | 低端 Android 真机耗时 |
| 用户不理解云处理 | 中 | 隐私说明曝光和反馈 |
| 图片工具竞争力不足 | 中 | 保存率和二次访问率 |

## 商业化

首版免费，不做付费墙。后续只在以下条件满足后考虑商业化：

- OCR/PDF 周导出稳定。
- 反馈集中要求批量处理、高清 OCR、云历史。
- 有明确 B 端或团队使用咨询。

可能收费能力：批量 OCR、批量 PDF、云历史、团队额度、API。基础单文件任务保持免费。
